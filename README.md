# Bug-Bounty Automation Tool

This is a simple automation tool built with Python to help in bug bounty reconnaissance and scanning.

## Prerequisites
Make sure you have Python installed on your system.

## Installation

1. Clone the repository:
```bash
git clone https://github.com/jyotirgillum10-ui/Bug-bounty-automationtool.git
cd Bug-bounty-automationtool
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the tool using:
```bash
python3 app.py
```
